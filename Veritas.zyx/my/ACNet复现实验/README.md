ACNet在MUSeg数据集上的复现实验报告

**一、模型概述**

**ACNet (Attention Complementary Network)** 是一种用于RGB-D语义分割的多模态融合模型。其核心思想在于通过**互补注意力机制**（Complementary Attention）在RGB和Depth分支之间实现信息交互，既保持模态独立性，又增强融合特征的判别性。

与双流平行结构不同，ACNet通过在编码阶段设置模态互补注意模块（ACM），在每个尺度特征图上动态学习两模态的加权关系，从而让网络更高效地整合颜色与几何信息。

在本次实验中，我们基于论文原理，完整复现了ACNet的训练与验证流程，并在**MUSeg数据集**上进行实验对比。

## 五、对比分析

与前期的多模态模型实验结果比较：

可以看到，ACNet在相同数据集上的表现明显优于DformerV2与FTransUNet，说明互补注意机制在RGB-D场景理解中具有较好的稳定性与泛化性。

## 六、总结与展望

本次实验成功复现了ACNet模型，并在MUSeg数据集上取得了**75.72%**的验证准确率。
这一结果表明，互补注意力在多模态融合任务中能有效弥合RGB与深度模态之间的特征鸿沟。

**可能的改进方向：**

1. 尝试引入**几何先验（DformerV2思想）**与互补注意的混合结构；
2. 使用**多尺度融合与上下文扩展**（参考FTransUNet实验四）以增强边界识别；
3. 增加**多模态自蒸馏损失**，提升模型对噪声深度图的鲁棒性；
4. 在**真实矿井或室内场景数据集**上进一步微调验证。
