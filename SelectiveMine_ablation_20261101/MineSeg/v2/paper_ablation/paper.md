# SelectiveMine selective_pa3 的冻结权重消融

日期：2026-11-01。本文记录 selective_pa3 第 12 轮权重在 FTransUNet 划分上的推理消融。权重没有重新训练。每个变体在评测时去掉一条已经训练好的路径；融合专家改变时，路由器按新的两路对数概率重算。百分比保留两位小数，由 JSON 中的原始分数换算。

被消融的检查点是 /root/autodl-tmp/MineSeg/v2/runs/selective_pa3/best.pth，轮次 12。它在 FTransUNet 训练集 1595 张上拟合，在验证集 788 张上按 16 类像素准确率保存，测试集 788 张在选择规则冻结之后才用于报告。三个名单互不相交。训练名单不再计算分数，因为这些图像参与了拟合。验证集和测试集都用同一套冻结变体、分辨率 768×896、单尺度、不做测试时增强。16 类协议把标签 0 计入混淆矩阵，标签 255 忽略。15 类协议同时忽略标签 0 和 255。完整模型在测试集上的 16 类像素准确率、平均像素准确率和平均交并比是 86.13%、74.52% 和 62.79%。与 selective_pa3/official_test.json 中三项原始分数的绝对差是 0.00001370、0.00000007 和 0.00000262。这三项原始分数都在 0 到 1 之间。MUSeg 论文 Table 5 引用的 CMX 是 86.30%、72.72% 和 61.83%。该引用不是这次重测。

## 1  数据和检查点

三个划分文件都在目录 /root/autodl-tmp/Visual-Multimodality/SSRS-main/FTransUNet，文件名是 train.txt、val.txt 和 test.txt。图像数分别是 1595、788 和 788。训练与验证的交集是 0，训练与测试的交集是 0，验证与测试的交集是 0。数据根目录是 /root/autodl-tmp/MUSeg/flat。评测把图像缩放到 768×896，corruption 设为 none，不做随机裁剪、颜色抖动或翻转。

selective_pa3 从 selective_ftrans 的第 7 轮继续训练 12 轮。保存规则是 select-pa：在验证集 16 类平均交并比不低于 60.80% 且平均像素准确率不低于 72.00% 的轮次中，保留 16 类像素准确率最高的一轮。被保存的是第 12 轮。消融使用这一份 best.pth，不使用后续 selective_pa4 或 selective_pa5 的权重。几何开度 tanh(open_raw) 与 mix 的乘积是 0.8109。评测前 mix 被填成 1，并按 joint 模式配置。

## 2  变体

完整模型同时计算外观解码器和融合路径。融合路径是深度门控后的 RGB-D 特征，经 relay 注入 HHA 几何，再由融合解码器输出，并加上按开度和深度是否存在缩放的几何 logits。路由器不读取真值。它的输入是两路概率、绝对差、两路熵、深度有效掩码和亮度。深度整幅缺失时，输出改用外观头。其余变体只改这一次前向里被使用的张量，不改卷积权重。去掉 HHA 或去掉深度时，对应输入被换成零张量。这不是把该分支从训练里拿掉之后重新优化，零输入落在训练分布之外。

表 1  每个变体在同一次前向中去掉的路径。

| 变体 | 去掉的内容 |
| --- | --- |
| 完整模型 | 不移除。路由器混合外观对数概率和融合对数概率。 |
| 常数 0.5 混合 | 路由器换成 0.5，两路专家仍是完整的外观头和融合头。 |
| 只用融合专家 | 去掉路由器和外观头，对融合 logits 做 argmax。 |
| 只用外观解码器 | 去掉深度、几何、融合解码器和路由器。 |
| 只用几何解码器 | 只保留 HHA 几何头。 |
| 去掉几何 logits | 融合解码器仍吃 relay 特征，不再加上几何头；路由器按新的融合专家重算。 |
| 去掉几何 logits 和路由器 | 对去掉几何头之后的融合解码器直接 argmax。 |
| 去掉 relay | RGB-D 门控特征直接进融合解码器，几何头仍相加；路由器重算。 |
| 去掉 relay 和路由器 | 对无 relay 的融合专家直接 argmax。 |
| 去掉几何支路 | 去掉 relay 和几何头，路由器仍把该解码器与外观头混合。 |
| 只留 RGB-D 门控解码器 | 去掉 relay、几何头和路由器。 |
| 去掉深度门控 | 可靠度门控的有效掩码置零，深度残差不注入；HHA、relay、几何头和路由器保留。 |
| 去掉 HHA | HHA 输入置零。深度门控、relay、几何头和路由器仍运行。 |
| 去掉深度和 HHA | 深度门控关闭且 HHA 置零，路由器仍混合外观头。 |
| 融合解码器只吃 RGB | 融合解码器接收未经深度注入、未经 relay 的 RGB 特征，不经过路由器。 |

## 5  结论

selective_pa3 第 12 轮在 FTransUNet 测试集上的单尺度 16 类结果是 86.13%、74.52% 和 62.79%。消融没有重新训练。因此这些差值表示已选权重里各条路径被拿掉之后的变化，不是从随机初始化或从同一起点重新训练一个缺模块模型的结果。测试集上，像素准确率、平均像素准确率和 16 类平均交并比下降最多的都是去掉深度和 HHA。训练名单有 1595 张，只用于说明检查点的拟合范围，没有在训练集上报告消融分数。

结果文件是 /root/autodl-tmp/MineSeg/v2/runs/selective_pa3_ablation/ablation.json。验证集和测试集的分文件是同目录的 ablation_val.json 和 ablation_test.json。对照用的已发表单尺度测试是 /root/autodl-tmp/MineSeg/v2/runs/selective_pa3/official_test.json。
